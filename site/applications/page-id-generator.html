Scan details




Page ID rule
LUX-PAGETYPE-CATEGORY-SUBCATEGORY-FILENAME-NUMBER
Category and subcategory are actual folder names; the structural articles directory is ignored. Filename uses the first two words. Existing IDs remain unchanged unless manually edited. The number increments within a page-type/category/subcategory group, from 01 to 99.
Folder scanning also works using the compatibility folder picker. Direct saving requires the File System Access API and permission to write the selected folder (desktop Chrome or Edge recommended). No Git commands are run.
